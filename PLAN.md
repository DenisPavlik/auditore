# Auditore — Trattoria Fiorentina

Вебсайт вигаданого флорентійського ресторану: портфоліо-проєкт для клієнтів на Upwork.
Мета: власник ресторану відкриває сайт і одразу хоче такий самий собі.

## Концепція

- **Стиль:** «записник Леонардо». Пергамент, акварель, сепієві ескізи пером, рукописні нотатки на полях.
  Палітра: флорентійська теракота, старе золото, оливковий, шавлієвий, чорнило.
- **Типографіка:** ренесансні шрифти з засічками для заголовків (Cormorant Garamond / Cinzel), читабельний serif для тексту, рукописний акцент для нотаток.
- **Оммаж Assassin's Creed:** лише тонкі пасхалки (пера, «Nulla è reale…» у футері, тераса «Terrazza Monteriggioni»). Жодних логотипів, ассетів чи символіки Ubisoft.
- **Мова:** English (міжнародні клієнти) з італійськими назвами розділів і страв.

## Двигун сезонів (основа всього сайту)

Сезон визначає тему, частинки, спешл-меню і стан тераси.

| Сезон | Місяці | Частинки | Акцент |
|---|---|---|---|
| Autunno | вер–лис | падаюче листя | теракота, бурштин |
| Inverno | гру–лют | сніжинки | холодне золото, глибокий червоний |
| Primavera | бер–тра | пелюстки, квіти | шавлія, рожевий |
| Estate | чер–сер | оливкове листя / світлячки ввечері | лимон, оливка |

- Сезон за замовчуванням визначається за датою (північна півкуля, метеорологічні сезони).
- **Перемикач сезонів у хедері:** 🍂 ❄️ 🌸 ☀️. Вибір зберігається в cookie, щоб сервер одразу рендерив правильну тему без мерехтіння.
- Перехід між сезонами анімований (розмиття «чорнилом / аквареллю»).
- Частинки малюються на власному легкому `<canvas>`. Вони ставляться на паузу, коли вкладка прихована, а з `prefers-reduced-motion` взагалі не запускаються.
- **Тераса:** за замовчуванням відкрита з 15 квітня по 31 жовтня (дати налаштовуються в адмінці). Адмін може вручну закрити її на сьогодні («дощ»). Коли тераса закрита, її столики на карті неактивні й візуально накриті.

## Модель даних (чернетка)

- `zones`: зала, тераса, вікна; `is_seasonal` для тераси
- `tables`: номер, зона, місткість min/max, координати та форма на SVG-плані, теги (біля вікна, тихо, кабінка)
- `opening_hours` + `closures`: графік і винятки (свята)
- `bookings`: столик, `during tstzrange`, гості, ім'я, email, телефон, побажання, статус, токен для керування бронюванням
  - **`EXCLUDE USING gist (table_id WITH =, during WITH &&) WHERE status <> 'cancelled'`**: подвійне бронювання неможливе на рівні БД, навіть якщо два запити прийдуть одночасно
- `seasons_config`: дати тераси, ручні перевизначення
- `menu_categories`, `menu_items`: назва, опис, ціна, алергени, ілюстрація, сезон (null = постійне меню)
- `gallery_images`

## Фази

### 1. Фундамент
- Скаффолд Next.js, Tailwind v4, шрифти, ESLint, структура
- Neon через `vercel integration add neon`, Drizzle, міграції, сиди
- Дизайн-токени + двигун сезонів (визначення сезону, cookie, CSS-змінні, перемикач)

### 2. Арт-дирекція та ассети
- Стайл-гайд: палітра, шрифти, шаблон промпту для акварелі
- Генерація: hero-сцени для кожного сезону, ілюстрації страв, орнаменти й рамки меню, частинки для кожного сезону (прозорий фон), монограма-логотип з оливковим вінком, текстура пергаменту
- Оптимізація: WebP/AVIF, `next/image`
- **Живий hero** (на кожен сезон): синемаграф-петля через image-to-video, де перший кадр = останній (полум'я свічки й ліхтаря, лоза гойдається, ластівки, кіт дихає). Статична картинка як poster (швидкий LCP), відео м'яко проявляється поверх. Окремий прозорий шар лози на передньому плані для паралаксу.
- **Пози й петлі La Volpe**: 6–8 поз від затвердженого лиса як референсу, з кожної коротка петля на тлі паперу в круглому медальйоні

### 3. Атмосфера
- Canvas-частинки для 4 сезонів: вітер, обертання, глибина (різні розміри й швидкості), реакція на скрол
- Hero: паралакс на скролі (шар лози швидший за сцену), листя падає і перед заголовком, і за ним, заголовок «пишеться чорнилом» при завантаженні
- Анімований перехід між сезонами
- Мікровзаємодії: ховери, появи при скролі, «чорнильні» підкреслення
- Курсор-виделка (з оливкою над клікабельним), клік лишає пляму пігменту сезону

### 4. Публічні сторінки
- **Home:** hero, історія, сезонний спешл, статус тераси («Terrazza aperta» / «chiusa fino a primavera»), тизер галереї, години роботи й локація, CTA
- **Menu:** розділи (Antipasti, Primi, Secondi, Dolci, Vini) + сезонна вкладка; ілюстроване оформлення в стилі записника, частинки
- **Gallery:** masonry-сітка + лайтбокс
- **La Storia:** історія родини Auditore (вигадана)
- **Contact / Hours:** карта, контакти

### 5. Бронювання
- Кроки: дата → гості → час → **SVG-план залу** (фільтри: зона, місткість, теги; зайняті й недоступні столики видно одразу) → контакти → **миттєве підтвердження**
- Сторінка підтвердження з анімацією, email-лист у стилі сайту, файл `.ics` для календаря
- Посилання для скасування або зміни бронювання (токен)
- Сервер перевіряє все повторно; при конфлікті показуємо дружню помилку й пропонуємо сусідній час або столик

### 6. Адмінка
- Вхід через Better Auth
- **Сьогодні:** таймлайн по столиках (Gantt), заповненість, хто має прийти найближчим часом
- Список бронювань: фільтри й пошук, статуси (confirmed / seated / completed / no-show / cancelled)
- Ручне бронювання (дзвінок телефоном)
- Сезони й тераса: дати, ручне закриття
- CRUD меню, сезонних спешлів, галереї (завантаження в Blob)
- Демо-доступ для клієнтів (read-only демо-акаунт)

### 7. Полірування та запуск
- SEO: метадані, OG-зображення для кожного сезону, JSON-LD `Restaurant`
- Доступність: клавіатура, контраст, альтернатива SVG-карті у вигляді списку столиків
- Продуктивність: Lighthouse 95+, мобільна версія як пріоритет
- Тематична 404, стани завантаження, порожні стани
- Деплой на Vercel, Upwork-картка через скіл `upwork-portfolio`

### 8. AI-помічник «La Volpe» (у дусі Скріпки з Office)
- Лис La Volpe у фартусі офіціанта (тонкий оммаж AC2; затверджено) стоїть у повний зріст у правому нижньому куті сайту, без рамки: петлі Seedance зняті на хромакеї й вирізані в прозоре відео (VP9 alpha для Chromium/Firefox, HEVC alpha для Safari; `scripts/key-volpe.py`). Шість станів: benvenuto, ascolta, scrive, consiglia, pensa, brinda. Іноді сам підказує щось до місця: на меню — «сьогодні трюфель із Сан-Мініато», на бронюванні — «на терасі ще є столик на двох».
- Чат на Claude API (Anthropic TypeScript SDK, tool runner) з інструментами:
  - `searchMenu`: фільтри (vegetarian / vegan / gluten-free / сезон), відповідає реальними стравами з БД
  - `checkAvailability`: дата, кількість гостей, зона → вільні слоти й столики
  - `createBooking`: створює бронювання лише після явного підтвердження гостя в UI (картка з кнопкою «Confirm»)
  - `getHoursAndInfo`: години, адреса, статус тераси
- Модель: Claude Haiku 5.5 (`claude-haiku-5-5`): швидка й дешева, для пошуку по меню і бронювання її досить (рішення Дениса)
- Захист: ліміт запитів на IP, обмеження довжини розмови, асистент відповідає лише на теми ресторану

### 9. 3D-зал (за потреби)
- React Three Fiber, стилізована ізометрична модель із тими самими даними столиків
